📣 Shabpa 3.18 is out

🆕 What's new
• 🪶 The feathers you have in the Telegram bot (daily feathers, feather codes, gifts from the admin) now move into the app; before, they never reached it and the app kept showing zero. A few seconds after you use a code or claim the daily feathers they are in the app (it also checks every 5 minutes by itself). The bot has to be linked to the app.
• 🦉 Write "code NIGHT100" to Boofi to use a feather code made in the bot; it is checked on the spot and the feathers arrive in the app. Each code works once per person.

🛠 Fixes
• ⚡ Speed limits: when Windows does not hand over the driver, Shabpa tries again after 4 seconds, three times (before, only every 30 seconds), and the error message no longer only says "restart Windows".
• 📝 If the speed-limit driver or the lighting driver (memory, fans) has a problem, the log now says who is in the way, to help find the cause.

⏳ Still not solved
• The exact cause of the speed-limit driver error (it appears now and then) is still unknown.
• The cause of the freeze on the Lighting page is still unknown; the new log should help find it.
