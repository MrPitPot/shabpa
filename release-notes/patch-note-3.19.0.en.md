📣 Shabpa 3.19 is out

🆕 What's new
• 🔗 Shabpa no longer uses GitHub; updates and links now come from Codeberg and GitLab (plus the Shabpa site and Arvan).
• 🪵 If the window gets slow after being hidden for a while, the log now records why.

⚡ Improved
• The game overlay and the warm night colour no longer make the screen flicker.
• The confirmation dialog belongs to the main window and cannot get lost.
• Memory is released once after the window is hidden.
