## چرا شب‌پا؟

- **یه برنامه‌ی سبک به جای پنج‌تا:** تایمر خاموشی، اورلی بازی، کنترل اینترنت هر برنامه، کارها و تمرکز، پشتیبان‌گیری و سلامت سیستم، همه توی تری.
- **بدون حساب، آمارگیری و تبلیغ.** همه‌چی فقط روی سیستم خودته.
- **امن:** هر زمان‌بندی یا پاک‌سازی قبل از اجرا اثرش رو نشون می‌ده؛ فایل‌ها فقط به سطل بازیافت می‌رن.
- **رایگان و متن‌باز (MIT).**
- **فارسی و انگلیسی** با ۲۱ تم رنگی.

## نصب

فایل `ShabpaSetup.exe` رو از [آخرین نسخه](https://github.com/MrPitPot/shabpa/releases/latest) بگیر و اجرا کن (ویندوز ۱۰ یا ۱۱، ۶۴ بیتی). اگه ‎.NET 10 نداشتی، نصب‌کننده نسخه‌ی رسمی مایکروسافت رو می‌گیره.

برنامه امضای دیجیتال پولی نداره، پس ویندوز ممکنه هشدار SmartScreen بده: **More info ← Run anyway**. کد کامل همین‌جاست و هر کسی می‌تونه خودش بسازدش.

**امنه؟** نصب‌کننده با GitHub Actions از روی همین کد عمومی ساخته می‌شه، هش SHA-256 هر نسخه کنارش منتشر می‌شه و نسخه‌ی 3.11.4 توی [VirusTotal (0 از 70)](https://www.virustotal.com/gui/file/b2a2da198cda8464232a4dcfd2b0a9947934740b8ee6f73a27854b77793c6f3c) تمیز اومد. برای چک کردن دانلودت: توی PowerShell دستور `Get-FileHash ShabpaSetup.exe` رو بزن و با فایل `.sha256` مقایسه کن.

## حریم خصوصی

- همه‌چی فقط روی همین سیستم ذخیره می‌شه (`%AppData%\Shabpa`)؛ حساب کاربری و آمارگیری نداره.
- فقط چیزهایی که خودت روشن می‌کنی به اینترنت وصل می‌شن: بررسی نسخه‌ی جدید، آب‌وهوا، تلگرام و تیکت پشتیبانی.
- هر زمان‌بندی، حذف و پاک‌سازی قبلش زمان و اثر دقیقش رو نشون می‌ده و تأیید می‌گیره.
